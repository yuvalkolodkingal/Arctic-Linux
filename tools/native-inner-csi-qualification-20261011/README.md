# Disabled Native inner observations and CSI classification

This separate execution lane retains the exact candidate image and every
original Native taskbar, app, media, networking, SELinux, Nix, authentication
and VM acceptance check. Its manifest is disabled. It does not build an image
or establish release qualification.

The runner imports the unchanged canonical evidence, apps and guest bundle.
Its own failure helper and Registry bind the actual runner and evidence module
instances. The accepted inner observer wraps the original run body and emits
only fixed role, guard, error-class and WAV predicate categories in
`host-native-inner-observation.json`. Its preparation loader and CLI are never
used by this runtime route. Optional diagnostic output preserves the original
failure and cleanup.

The selected complete-CSI scanner and companion are preserved as whole accepted
Source components. The scanner supplies the same whole privacy admission with
corrected complete CSI classification boundaries. The companion is pinned for
Source provenance; its historical standalone scanner loader and CLI are not
executed by this Native lane. No privacy exceptions are introduced. The inner
member must pass the same original text privacy, fixed schema, identity and
generation checks before partial retention. Rejected originals remain rejected.

The existing Native workflow, manifest, READY state and activation marker remain
unchanged. This lane has a distinct workflow, branch, paths, manifest and absent
activation marker. Both execution and image checkouts request complete history.
The Source context distinguishes the execution base from the unchanged image
Source. CI adds only an explicit exclusion for this separate qualification
branch; its other triggers and jobs remain unchanged.

Source tests use only public code and owned synthetic text/WAV fixtures. They
do not authenticate old runtime causes or read retained original evidence. A
new Source-bound terminal consumer and independent review are required before
any future private terminal evidence is opened. Root owns operational readiness,
public activation and any new VM run.
