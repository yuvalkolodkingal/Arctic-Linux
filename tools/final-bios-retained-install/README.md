# Retained failure BIOS installation lane

This separate first-marker-ADD lane binds the whole frozen f68 retained-originals
helper and published f23 runtime. It invokes the same original encrypted offline
BIOS installation and installed boot with unchanged SourceA/F10, real guest
security/input predicates, 2400-second installer and 6600-second host limits.
The copied original main changes only its explicit admission dependency to the
new guard. Original main code, invocation, primary failure, group/container/image
cleanup, success publication and strict whole-UART acceptance remain exact.

On failure, the exact retained helper snapshots two complete UART and four fixed
original PNG buffers before original cleanup. Only originals admitted by that
helper's strict screens can enter public output. Rejected originals stay private;
there is no unscreened failure tail. OCR is supplementary; manual original PNG
review remains mandatory. Finite Source causes are diagnosis, never qualification.

The old CI workflow remains exact because it is in the accepted helper closure.
Ordinary Source CI may run on this new branch; it does not invoke a VM lane.
This preparation adds no activation marker. Root must independently review the
full composition, original first-ADD guard and Source peer before public activation.
