These scripts captured real Nautilus and Kitty/Fish windows in a disposable Fedora 44 container. Bind the repository to `/source` read-only and a writable output folder to `/capture`, install nautilus, sway, grim, dbus-daemon, fish, kitty and fontconfig, create a `capture` user with home `/home/capture`, and run each script as that user under `dbus-run-session`. `capture-terminal.sh` also uses the repository’s compiled `fetch/arctic-fetch-3d` at `/usr/libexec/arctic/arctic-fetch-3d`. Only the displayed shell/terminal fields are enabled in its fetch configuration. The screenshots demonstrate application appearance; they are not a recording of an installed Arctic system.
