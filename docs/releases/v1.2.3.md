# Arctic Linux 1.2.3

Arctic Linux 1.2.3 keeps the Fedora 44 base and the 1.2.2 desktop, and makes starting the
computer quicker and quieter:

- **One passphrase when updates are installed.** Updates are still installed at a restart,
  before the desktop. Until now that boot always ended with a second full restart, so an
  encrypted disk asked for its passphrase, installed the updates, restarted and asked again.
  Now the computer goes straight on to the login screen (a systemd soft-reboot: the kernel keeps
  running and the disk stays unlocked). Only an update that brings a new kernel, a graphics
  driver or firmware still restarts once more, because nothing else can load those. This also
  skips the firmware, the boot menu and the second start-up on disks without encryption.
- **A shorter boot menu.** On a computer with only Arctic Linux the boot menu starts it after
  3 seconds instead of 5; any arrow key still stops the countdown. Installed next to another
  system, the menu keeps its 5 seconds. (New installations.)
- **Fewer disk writes.** The btrfs subvolumes are mounted with `noatime`, so reading a file no
  longer writes its access time back, which matters most right after a snapshot. (New
  installations; on an existing one, add `noatime` to the btrfs lines of `/etc/fstab`.)
- **Compressed swap in memory (zram)** is now a named part of the image rather than something
  another package happened to bring.

Existing systems on the stable channel get the update change with `arctic-update now`, then
`arctic-update apply`; it takes effect from the update after that one.
