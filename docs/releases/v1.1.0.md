## What's new in 1.1

- **Web apps follow the desktop's light/dark theme live**, including websites that use the
  system appearance setting. No page reload is needed.
- **Chromium is included for calling sites.** New WhatsApp apps select an available
  Chromium-family engine automatically. Terminal installs use the same recommendation as
  Get apps. Fedora's native WebKit engine remains available for other apps.
- **Fish and Nautilus are the installer defaults.** This ISO also includes the WhatsApp
  preview/install fix and the accelerated video playback changes merged after 1.0.

For an existing WhatsApp app, choose **Chromium** under **Settings → Web apps → WhatsApp →
Open with**, then reopen it. You may need to pair again; the original profile is kept.
Whether WhatsApp offers web calls also depends on its service and your account.

Existing Arctic systems can update without reinstalling:

```sh
sudo dnf --refresh upgrade
arctic-shell --restart
```
