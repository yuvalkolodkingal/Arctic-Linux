# Arctic Linux 1.2.2

Arctic Linux 1.2.2 replaces the unpublished 1.2.1 image. It keeps the Fedora 44 base and the
1.2.1 desktop, installer, taskbar, wallpaper and update work, with two changes on top:

- **Voice typing with OpenWhispr.** The built-in VoxType dictation is gone: no model download
  during installation, no dictation setup service, no taskbar dictation pill. Instead,
  **Settings → Voice typing** installs [OpenWhispr](https://openwhispr.com) from its official
  GitHub releases (the published SHA-256 is checked before installing), updates or removes it,
  and can start it at login. **Super + Ctrl + X** opens OpenWhispr; dictate with OpenWhispr's own
  shortcut (F8 by default). Upgraded systems delete the old VoxType binaries and models once.
- **Wallpaper rotation keeps your colours.** A wallpaper that changes by itself no longer
  recolours the desktop; the colours stay the ones from the wallpaper you picked. Picking a
  wallpaper or turning rotation off goes back to your own choice.

Existing systems on the stable channel get these with `arctic-update now`, then
`arctic-update apply`.
