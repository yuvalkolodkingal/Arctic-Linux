# Arctic Linux 1.2.1

Arctic Linux 1.2.1 is the smaller replacement image for x86_64 systems. It keeps the Fedora 44
base and adds the lightweight desktop, the project photo collection, direct official VoxType
integration, and the installer, taskbar and update fixes described below.

> **Publication status:** prepared, but not published. The replacement artifact has passed only
> its producer build, size and startup checks. Every exact-image qualification lane listed below
> remains pending for this artifact. A source test or successful ISO build is not release
> qualification.

## What changed

- **Official VoxType dictation:** Arctic integrates signed upstream VoxType 1.1.1 directly.
  VoxType records, transcribes, cancels and inserts; Arctic provides verified automatic online
  setup, a retryable offline first-boot queue, Settings/status, Mango shortcuts and the recording
  indicator. The executable and multilingual Whisper weights stay out of the live ISO.
- **Safe local setup:** Hebrew, English and automatic language selection use local Whisper.
  Downloads disclose their fixed asset size and verify the upstream signature, exact size and
  SHA-256 before becoming ready. A failed model download never fails the OS installation.
  Vulkan is optional; if it fails, the error remains visible and the user explicitly selects CPU
  before recording again.
- **First-login reliability:** the welcome marker is consumed only after the persistent welcome
  card opens. If the shell IPC endpoint is not ready during login, the marker remains and the
  normal startup path retries, so the card is not silently lost.
- **Wallpapers:** the built-in gallery uses the project's 28-photo collection. Fresh accounts
  start with *City Afterglow*. It includes the original 2048 × 1152 *Ember Clouds, City
  Silhouette* master, SHA-256
  `7af8cb5ce0d87773109d759afdd1d14ef22ce7e84fdc1533da1539083cd11b0b`, without regeneration or
  upscaling. Updates preserve existing choices. Packaged photos can be hidden per account and
  restored; personal pictures can be deleted normally.
- **Updates explain themselves:** a **What's New** card is keyed by the installed package update
  ID and appears once per account after each Arctic update. Settings can reopen the installed
  summary and full release notes.
- **Lighter defaults:** GNOME Web (Epiphany), Foot, GTK3 PCManFM, XArchiver, Celluloid,
  FeatherPad, Nano and Fish/Bash. Larger catalog apps remain optional. **Remove apps** has its
  own menu.
- **Desktop and installer fixes:** taskbar edge/frame placement, auto-hide and dodge, exclusive
  zones and duplicate-bar prevention; the full-battery icon; lock-screen clock; wallpaper
  settings; repository-aware update detection; and restoration of exactly one installer window
  with its page, keyboard and engine state after a console or output change.

## Official VoxType behavior and limits

The [VoxType 1.1.1](https://github.com/peteonrails/voxtype) daemon runs local Whisper and inserts
through `wtype`. Arctic disables remote inference, VoxType's input-device hotkey listener,
transcript notifications, clipboard fallback and transcript post-processing. The user service is
restricted to local Unix sockets and uses error-only logging. Exact-image privacy inspection is
still pending; source configuration alone is not runtime proof.

| Selected CPU path | Fixed app and model download |
|---|---:|
| Baseline + Whisper Small | 506,440,871 bytes (506.4 MB) |
| AVX2 + Whisper Large v3 Turbo Q5 | 593,457,131 bytes (593.5 MB) |

Optional Vulkan support adds 66,575,872 bytes (66.6 MB). Package dependencies may add more. These
are download sizes, not final installed-disk measurements. See [Local dictation](../wiki/Local-Dictation.md)
for the earlier small public read-speech measurements and their limits. Current-image Hebrew and
English results remain pending.

## Updating an existing installation

The release is intended for the signed stable `arctic` repository; the testing channel is not
required. Existing systems keep their app choices, wallpapers and personal settings.

```sh
arctic-update channel
arctic-update now
arctic-update apply
```

If `channel` reports testing, run `arctic-update channel stable` before `now`. Save your work
before `apply`; it restarts into the prepared offline transaction. The Arctic signing-key
fingerprint is `80F75DE9A23B632246FD1FF1BD1A642B5436645A`.

No final stable package publication or exact signed-update/reboot result is claimed here.
